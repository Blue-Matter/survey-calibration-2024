This repository contains the R code for the survey calibration without CF (comparative fishing) 

Various sub-projects are denoted by letter prefixes, as follows:

- A: validation comparing CF rho and spatiotemporal rho for Newfoundland survey
- B: Same as A, with size-based analysis
- C: attempted validation comparing CF rho and spatiotemporal rho for Strait of Georgia dogfish survey, not possible due to the long survey gap between changes in hook type
- D: validation comparing CF rho and spatiotemporal rho for NEFSC spring survey
- E: summary figures of A and D for manuscript
- F: simulation study
- G: calibration for 0A1CD Greenland halibut (Paamiut/Helga Maria/Tarajoq vessels)
